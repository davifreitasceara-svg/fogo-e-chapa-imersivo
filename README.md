# Fogo e Chapa Imersivo

Atue como um Desenvolvedor Front-end Sênior e UI/UX Designer especialista em experiências imersivas.

Preciso que você crie o código completo de uma Landing Page e sistema de navegação para uma hamburgueria premium chamada "Fogo e Chapa". O design deve ser moderno, apetitoso, com um tema que remeta a brasa, fogo e grelha (cores principais: Preto Carvão, Laranja Fogo, Vermelho Brasa e detalhes em Amarelo Ouro).

A aplicação deve ser responsiva, moderna e conter os seguintes elementos e seções:

1. Efeitos e Interações 3D (Core da Experiência):

Utilize bibliotecas de animação (como Framer Motion) e simule elementos 3D (ou integre Three.js/Spline se aplicável) na interface.

Hero Section: O elemento central ao abrir o site deve ser um Hambúrguer 3D flutuante (ou uma imagem de altíssima qualidade com efeito Parallax/Tilt 3D) que se move levemente conforme o movimento do mouse. Atrás dele, partículas sutis simulando faíscas de brasa subindo.

2. Barra de Navegação (Navbar):

Logo "Fogo e Chapa" estilizada.

Links âncora: Início, Cardápio, Sobre Nós, Contato.

Um botão de "Entrar / Cadastrar" com um efeito de hover vibrante (brilho ou mudança de cor que remeta ao fogo).

3. Tela de Login (Modal ou Página Dedicada):

Uma interface de login elegante (Glassmorphism sobre fundo escuro).

Campos: E-mail e Senha.

Botões para login social (Google, Apple).

Animação suave de transição ao abrir e fechar a tela de login.

4. Seção de Cardápio Interativo:

Filtros em formato de abas (Tabs): "🔥 Hambúrgueres" e "🧊 Bebidas".

Hambúrgueres: Cards com imagens suculentas. Ao passar o mouse (hover), o card deve ter um efeito 3D (tilt) saltando para frente, com um botão "Adicionar ao Carrinho" surgindo.

Bebidas: Cervejas artesanais, refrigerantes e drinks, mantendo a mesma interação visual dos cards.

5. Footer (Rodapé):

Redes sociais, endereço, horário de funcionamento e links rápidos.

Tecnologias preferidas: React, Tailwind CSS, Framer Motion e Lucide Icons. Por favor, gere o código estruturado, bonito e pronto para ser visualizado. Crie um layout que realmente dê fome no usuário através de um visual escuro e elegante!

Dicas extras para o seu projeto:

Se for usar ferramentas apenas visuais para gerar a imagem do site (como Midjourney ou DALL-E), use este prompt mais curto: "UI/UX design of a modern burger restaurant website named 'Fogo e Chapa'. Dark mode, charcoal and fire colors. 3D floating burger in the center, sparks flying. Menu sections for Burgers and Drinks. Login button. Highly detailed, dribbble style, 8k resolution, photorealistic elements, immersive 3D web interactions."

Para o hambúrguer 3D real no site programado, você pode procurar modelos gratuitos na ferramenta Spline (spline.design) e incorporar diretamente no código que a IA gerar.
